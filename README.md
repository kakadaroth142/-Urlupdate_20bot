## 🚀 ដំឡើងលម្អិត

### ឯកសារលម្អិត 1: ដំឡើងលម្អិតក្នុងលើកម្មវិធីផ្ទាល់ខ្លួន

```bash
# ក្លូន Repository
git clone https://github.com/kakadaroth142/-Urlupdate_20bot.git
cd -Urlupdate_20bot

# បង្កើត virtual environment
python -m venv venv

# ប្រើប្រាស់ virtual environment
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

# ដំឡើង dependencies
pip install -r requirements.txt

# រត់ Bot
python bot.py
```

### ឯកសារលម្អិត 2: ដាក់លើ Railway.app (ផ្សាយលាយ)

1. ចូលទៅ [Railway.app](https://railway.app)
2. ចុច `New Project` → `Deploy from GitHub`
3. ជ្រើសរើស `-Urlupdate_20bot`
4. Railway នឹងប្រើប្រាស់ TOKEN ពី .env ដោយស្វ័យប្រវត្ត
5. ចុច `Deploy` ហើយរង់ចាំ
